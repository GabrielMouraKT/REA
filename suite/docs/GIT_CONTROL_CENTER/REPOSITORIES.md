# Repositórios

Tela: Git Control Center › Repositories (escolha o projeto primeiro).

| Ação                     | O que faz                                                 | Observações                                                      |
| ------------------------ | --------------------------------------------------------- | ---------------------------------------------------------------- |
| Vincular pasta existente | Liga ao projeto uma pasta que já usa Git                  | Aceita subpasta: o REA acha a raiz. Vincular de novo não duplica |
| Iniciar repositório novo | `git init -b main` numa pasta e vincula                   | Recusa se a pasta já for repositório                             |
| Clonar                   | `git clone` para uma pasta nova dentro da pasta escolhida | Só `https://`, `ssh://`, `git@host:…` e `file://`                |
| Criar no GitHub          | Cria público ou privado na sua conta e configura `origin` | Pede confirmação; não envia nada sozinho                         |
| Desvincular              | Remove só o vínculo com o projeto                         | Nenhum arquivo ou histórico é apagado                            |
| Abrir pasta              | Abre no Explorador                                        | —                                                                |

Consulta de repositórios do GitHub (nome, visibilidade, atualização, descrição, endereço): Accounts.
Renomear, arquivar e excluir repositórios no GitHub: próxima etapa (com confirmação dupla).
